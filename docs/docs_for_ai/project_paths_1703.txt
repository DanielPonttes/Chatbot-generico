app/
  main.py                         -> entrada FastAPI, lifespan, CORS e rotas estaticas
  api/
    routes.py                     -> endpoints /chat, /health, /integrations, /rag, /notifications
    db.py                         -> SQLite de notificacoes salvas
  core/
    config.py                     -> configuracoes via env/.env
  models/
    schemas.py                    -> Pydantic models para requests/responses
  services/
    integration_catalog.py        -> catalogo PostgreSQL remoto + API Spring Boot
    llm_provider.py               -> Gemini, Ollama, HuggingFace e factory
    memory.py                     -> historico em RAM ou SQLite
    notification_type.yaml        -> templates e variaveis de notificacao
    persona_service.py            -> personas, perfis, tipos e prompt proativo
    proactive_context.py          -> contexto real de sala/sensor/pessoa/medicoes
  rag/
    ingest.py                     -> ingestao de documentos
    retriever.py                  -> busca vetorial com metadados
    vector_db.py                  -> Chroma + embeddings Google
  static/
    index.html                    -> chat principal
    notifications.html            -> gerador e avaliador de notificacoes
    rag.html                      -> visualizador RAG

  services/llm_personas.md        -> services, LLM, personas e notificacoes
